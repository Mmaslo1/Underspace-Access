# Underspace Access

A blind accessibility mod for **Underspace** (Steam PC), made by a totally blind player with Claude Code.
Runs on MelonLoader 0.7.3 and speaks through JAWS using the Prism library (lib/prism, MPL 2.0).

- `src/UnderspaceAccess/` - the mod code (C#)
- `UNDERSPACE_GUIDE.txt` - how to play with the mod
- `Underspace_Controls.txt` - all keys
- `STATUS_AND_TODO.txt` - what works and what is next
- `Underspace.jcf` / `.jkm` - JAWS settings for the game

## How to install
Download the newest **UnderspaceAccess_<version>.zip** from the [Releases page](https://github.com/Mmaslo1/Underspace-Access/releases/latest)
and follow "01 START HERE - HOW TO INSTALL.txt" inside it (MelonLoader 0.7.3 first, then copy the files into the game folder).

**Updates:** from 0.10.3 on, the mod checks for a new version when the game starts and says so. Press **Shift+F12** to download it; it installs itself after you close the game.

## Want to help?
Thank you! Please send changes as a **pull request** and say what it fixes and how you tested it.
The player makes the final call on every change, so explain it in plain words.
Everything must work by keyboard and speech, no mouse or screen steps.
